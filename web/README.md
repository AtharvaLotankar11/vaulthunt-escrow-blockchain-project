# VaultHunt web app

Next.js (App Router, JavaScript), Tailwind v4, wagmi + viem. Phases 6 to 8 of `tasks-docs/milestone.md` (foundation, core flows, jury, profile, leaderboard, live feed).

## Pages
| Page | What it does |
|---|---|
| `/` | landing, live numbers from the chain |
| `/programs` | all bounty vaults |
| `/programs/new` | create a vault: name, scope, reward tiers, deposit; creates your encryption key |
| `/programs/[id]` | vault, rewards, scope, reports; owner tools (add funds, withdraw, publish profile) |
| `/programs/[id]/submit` | hunter: commit, encrypt, upload, reveal (one button) |
| `/company` | read decrypted reports, verify the hash, accept, reject, back up your key |
| `/hunter` | my reports, finish a reveal, dispute, claim, test BBT faucet |
| `/jury`, `/jury/[caseId]` | stake and leave the pool, vote hidden then reveal, resolve |
| `/profile/[address]` | soulbound badge, level, XP |
| `/leaderboard` | top hunters |
| `/demo` | Demo Mode: plays a whole scenario by itself on the local chain (no wallet needed) |

On the local chain a **Demo: time travel** bar appears at the bottom: it moves the chain clock forward so review deadlines and jury windows pass in seconds.

## First time
```
pnpm install
pnpm sync        # copies ABIs + addresses from ../contracts (needs `forge build` once)
```

## Run it locally (three terminals)
1. `anvil`                                   (in the contracts folder or anywhere)
2. In `contracts\`: run `script/Deploy.s.sol`, then `script/Seed.s.sol` (see contracts\SECURITY.md section 6)
3. In `web\`: `pnpm dev`, then open http://localhost:3000

Click **Connect wallet** (MetaMask). If MetaMask is on another network, click the "Wrong network" button; MetaMask offers to add or switch to Anvil.
The "Live on chain" panel should show Programs 1, Jurors 5, Reports 0 and "Contracts wired".

## Report storage
Reports are encrypted in the browser and uploaded through `/api/ipfs`. With no setup they are stored in `web/.data/ipfs` (ignored by git). To use real IPFS, put a free Pinata key in `web/.env.local` as `PINATA_JWT=...` (server side only) and restart `pnpm dev`.

## Your secrets live in this browser
The company's private key, a hunter's unrevealed report text and salt, and a juror's vote and salt are kept in this browser's localStorage. Use the **Back up my encryption key** button on the Company page. Use the same browser and the same site address (localhost:3000) for the whole demo.

## Commands
| Command | What it does |
|---|---|
| `pnpm dev` | development server |
| `pnpm build` / `pnpm start` | production build / run it |
| `pnpm lint` | ESLint |
| `pnpm sync` | regenerate `src/contracts/abis.json` and `addresses.json` after any contract change or new deployment |

## Folders
- `src/app` pages, layout, global styles and design tokens
- `src/components` ui (chips, panels), art (arcs, rings), layout, wallet, home
- `src/lib` wagmi config, contract helpers (`contracts.js`), small utilities
- `src/contracts` generated by `pnpm sync`; do not edit by hand
- `scripts/sync-abis.js` the Foundry-to-app bridge
